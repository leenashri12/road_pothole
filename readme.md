# 🛣️ Road Pothole Detection System

An AI-powered road condition monitoring system that detects potholes from images and videos using YOLO and OpenVINO optimization.

---

## 📌 Project Overview

This project helps in automatic pothole detection on roads using Deep Learning techniques.  
The system can process both images and videos and highlight potholes detected on the road surface.

A Streamlit dashboard is used for user interaction and visualization.

---

## 🚀 Features

- Pothole detection from images
- Pothole detection from videos
- Real-time inference dashboard
- OpenVINO optimized model
- User-friendly Streamlit interface

---

## 🧠 Technologies Used

- Python
- YOLO (Ultralytics)
- OpenVINO
- Streamlit
- OpenCV
- NumPy
- PyTorch
